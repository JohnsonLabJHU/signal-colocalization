Segment a reference channel (Cellpose) and measure signal-channel colocalization inside each cell — per-cell and per-image (Pearson, Manders, Jaccard, positive fraction). Runs on the lab analysis platform; results are written back to the experiment and logged here, auditable and reproducible.

📖 How to use this tool — read me first

This tool does two jobs in one pass: it stores your microscopy images in the lab cloud (durable, searchable, backed up) and runs a colocalization analysis on the GPU platform. You never attach anything in eLabFTW by hand, and you don't need the separate image-upload tool — uploading here archives the data for you too.

A · Step by step

  1. Pick the experiment (Step 1). Click the box to browse a dropdown of every experiment, or type part of the title or the #id to filter. Completed studies are hidden unless you tick "include completed studies."
  2. Choose your images (Step 2) — two ways. Option A · Upload new images: fill the session fields (tissue, modality, magnification, date), drag in a folder or browse to your files (.oir, .czi, .tif…), complete anything flagged in the confirm table (animal, eye/slide, Target-Fluorophore markers) so each file is renamed to the lab convention, then click Upload — the files are saved to the cloud archive (searchable & backed up) and analyzed in one step. Option B · Use images already in this experiment: tick images already uploaded (from any tool) to analyze them without re-uploading. Either way the pipeline reads them from the cloud, and a file already in the archive is detected and reused — never uploaded twice. For cell-culture sessions, animal & eye are skipped automatically.
  3. Define what to segment and measure (Step 3). A reference set is the cell population you outline (e.g. RBPMS to find retinal ganglion cells). A signal channel is what you measure inside those outlined cells (e.g. a dendrimer). Add as many of each as you need — every signal is measured against every reference.
  4. Set options (Step 4) — usually leave the defaults.
  5. Submit. The run is queued; the GPU platform pulls your images from the cloud, segments the cells, measures colocalization, and writes the results back automatically. Nothing else for you to do.
  6. Find your results under "Recent analyses on this experiment" at the bottom. Each run shows its status (Queued → Running → Done). When Done, click open — the results are attached to the experiment and to the run record: an Excel workbook (the numbers), per-cell and per-image CSVs, and QC images showing exactly which cells were outlined so you can sanity-check before trusting the values.

B · What each setting means (and when to change it)

Channels are numbered from 0: if DAPI is the 1st channel it is channel 0, the 2nd is 1, and so on.

SettingWhat it doesWhen you'd change it
Reference channelThe channel whose cells get outlined (segmented).Set to the channel holding your cell-identity marker.
Cellpose modelThe pretrained segmentation network. cpdino_BRN3A and cpdino_RPBMS are fine-tuned on retinal ganglion-cell nuclear (BRN3A/POU4F1) and cytoplasmic (RBPMS) staining; cpsam_v2/cpdino are general-purpose.Match the model to how your marker looks. Use a retinal model for RGC markers; a general model for other cell types or stains.
Diameter (px)The expected cell diameter. Blank = Cellpose estimates it automatically.Enter a number only if auto-sizing under- or over-segments; measure a few cells in ImageJ/Fiji to get it.
Flow thr (flow threshold)How strict Cellpose is about mask shape (maximum allowed flow error). Higher = more, looser masks; lower = fewer, cleaner masks. Default 0.4.Raise toward 0.6 if real cells are being missed; lower toward 0.2 if you get spurious blobs.
Cellprob thr (cell-probability threshold)How confident a pixel must be to count as part of a cell. Lower = larger/more masks; higher = smaller/fewer. Default 0.0.Lower (e.g. −2) to recover dim cells; raise (e.g. +2) to drop faint/background objects.
Min sizeDiscards any mask smaller than this many pixels — a debris/noise filter.Raise to remove small artifacts; lower if genuine small cells are being dropped.
NormalizeRescales each image's intensity before segmentation so brightness differences between images don't skew the result. Usually "yes."Turn off only if you deliberately need to segment on raw, un-scaled intensities.
Signal channelThe channel whose signal is measured inside each outlined cell.Set to the channel of the marker you're testing for colocalization.
Threshold (method)How the tool decides which signal pixels are "positive." otsu picks the cutoff automatically (Otsu 1979); percentile/absolute let you set it; none counts all pixels.Otsu is a good default. Use absolute when you need the exact same cutoff on every image for a fair cross-condition comparison.
Threshold valueThe number used by the percentile/absolute methods (ignored for otsu/none).Set it when you choose percentile or absolute.
Positive-fraction cutoffThe fraction of a cell's area that must be signal-positive before that whole cell is called "positive."Raise toward 1.0 to require strong, widespread signal; lower to also count faintly-labeled cells.
Z-projection / Time / Scene indexFor multi-dimensional files: how a z-stack is flattened (max/mean/first) and which timepoint/scene to analyze.Change only for multi-z, time-lapse, or multi-scene images.
Compute deviceWhere segmentation runs; "auto" uses the GPU when available.Leave on auto.

C · Understanding the output numbers

For each outlined cell the workbook reports colocalization between the reference and signal: Manders' coefficients (the fraction of one channel's signal that overlaps the other — the intuitive "how much of A sits on B"; Manders et al. 1993), Pearson's correlation (how the two intensities co-vary — powerful but easy to misread, so interpret alongside Manders; Dunn et al. 2011), a Jaccard overlap index, and the positive fraction of the cell. Per-image rows aggregate across all cells in that image. Always glance at the QC mask images first — a beautiful correlation is meaningless if the masks landed on the wrong structures.

References: Stringer et al., Nat Methods 18:100 (2021) — Cellpose; Manders et al., J Microsc 169:375 (1993); Costes et al., Biophys J 86:3993 (2004); Dunn et al., Am J Physiol Cell Physiol 300:C723 (2011); Aaron et al., J Cell Sci 131:jcs211847 (2018); Otsu, IEEE Trans SMC 9:62 (1979).
